# VIRAL GAMING CLIPS

Generatore gratuito di clip gaming verticali a partire da registrazioni lunghe.

## Obiettivo

Creare automaticamente più clip separate, ciascuna esportata come file MP4, individuando i momenti più interessanti di una registrazione.

## Specifiche desiderate

- Formato verticale 9:16, obiettivo 1080x1920.
- Durata indicativa: 15–40 secondi per clip.
- Rilevamento automatico dei momenti salienti.
- Sottotitoli in italiano, grandi e leggibili, con parole chiave evidenziate.
- Zoom, tagli rapidi ed effetti leggeri opzionali.
- Ogni momento selezionato deve diventare un file distinto.

## Vincoli

- Budget: 0 €, usando strumenti gratuiti e open source.
- Rispettare i diritti e le autorizzazioni del proprietario dei video.
- Non dipendere da hosting gratuito inadatto a file video molto grandi o elaborazioni lunghe.

## Stato

Repository inizializzato e specifiche di progetto documentate. La pipeline di elaborazione automatica deve ancora essere implementata.
